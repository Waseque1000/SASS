# Build a Modern SaaS Website Starter

Build a professional, modern, responsive SaaS website using **Next.js with JavaScript and JSX**. For now, do not build any specific SaaS product or product functionality. Create only the core website structure, authentication pages, dashboard layout, and subscription system interface.

## 1. Homepage
Create a beautiful, modern SaaS landing page with:
- Clean navigation bar with logo placeholder
- Hero section with headline, description, and call-to-action buttons
- Features section with generic placeholder content
- Benefits section
- Pricing plans section
- Frequently asked questions
- Footer with contact, privacy policy, and terms links
- Responsive mobile navigation

Use placeholder text that can be customized after the SaaS product is selected.

## 2. Authentication
Create the following pages:
- Registration page
- Login page
- Forgot password page
- Reset password page
- Email verification flow

Use Supabase Authentication for secure user authentication. Include form validation, loading states, error messages, and success feedback.

## 3. User Dashboard
Create a protected dashboard layout containing:
- Sidebar navigation
- Dashboard overview
- User profile and account settings
- Subscription and billing page
- Help and support page

Do not add any product-specific tools, data processing, or business functionality. Keep the dashboard as a clean, reusable placeholder.

## 4. Subscription and Pricing
Create a subscription system interface with:
- Free plan
- Pro monthly plan
- Pro yearly plan
- Pricing comparison table
- Upgrade and downgrade buttons
- Subscription status
- Billing history interface
- Cancel subscription option
- Checkout page design

Prepare the architecture for payment gateway integration, but do not process real payments until the payment provider is configured. Subscription status and access permissions must ultimately be verified on the server.

## 5. Design Requirements
- Premium, modern SaaS design
- Minimalist layout with clean whitespace
- Consistent typography and spacing
- Professional buttons, cards, forms, and navigation
- Fully responsive on mobile, tablet, and desktop
- Light theme with an optional dark mode
- Accessible forms and interface elements
- Consistent reusable components

Avoid excessive animations, unnecessary sections, and complicated layouts.

## 6. Technical Requirements
- Next.js with JavaScript and JSX only
- Supabase Authentication
- Supabase PostgreSQL for user profiles and subscription records
- Reusable components and a clear project structure
- Protected routes for authenticated users
- Secure server-side authorization and environment variables
- Proper loading, empty, error, and success states

## 7. Important Restrictions
Do not select or invent a SaaS product idea.
Do not implement product-specific features.
Do not generate fake customer testimonials, fabricated usage statistics, or fake payment confirmations.
Do not expose secret keys or trust client-side subscription status.

The goal is to create a complete, polished **SaaS website foundation** with a homepage, authentication, dashboard shell, pricing page, and subscription management interface. The actual SaaS product will be decided and implemented later.

Build the website as a working application, not just a static visual mockup.
